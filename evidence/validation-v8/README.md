# V8 prospective model-graph study

Start with the [English guide](../../docs/reproduction-v8.md) or [中文教程](../../docs/reproduction-v8.zh-CN.md).

- `protocol.json`: frozen before the 96 provider calls; original collector and evaluator hashes.
- `reproduction-records.zip`: 48 complete model records, including separately captured provider payloads and original response bytes; 1,440 paired controller executions and the batch manifest. No account credentials.
- `summary.json` and `scores.jsonl`: regenerated by `npm run verify:v8`.
- `analysis.json`: exploratory question-cluster bootstrap, normalized payload lengths and annotation caveats.
- `disagreements-for-review.json`: all 20 original-label disagreements; independent human review is pending.
- `tradeoffs.*`: plots drawn from the verified records; plotting source is `scripts/plot-v8.py`.
- `verifier-amendment.md`: transparent correction to matching duplicate identical HTTP requests; frozen code and records remain preserved.

48 model plans are executable; 28 agree with original labels. The reuse methods reduce operator calls from 331 to 261 against restart. Frontier and budget variants do **not** improve disclosure over greedy repair in this batch. Arithmetic receivers use real loopback HTTP within the collector's Node process. Neither the arithmetic endpoint nor controlled intervention is a fresh LLM call.

The study uses 24 previously unused company-year reports; it remains a restricted public financial-table population. Five conditions and two model plans from a question are dependent observations. Report counts at their actual level, not as 1,440 independent model tasks.

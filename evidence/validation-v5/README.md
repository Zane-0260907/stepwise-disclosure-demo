# Preserved v5 experiment

600 tasks / 1,579 real provider calls, retained in full. This is a historical experiment using the earlier table converter. Some year headers were incorrectly hidden as business values; read the [correction](../../docs/table-adapter-correction.md) before interpreting numerical differences.

The current study is [v6](../validation-v6/). V5 outcomes informed development of the corrected adapter and cannot be reused as an independent v6 test set. Protocol, original records, failure cases and scores remain unchanged.

To verify: extract `reproduction-records.zip` at the repository root and run `npm run verify:v5`. No key is needed.

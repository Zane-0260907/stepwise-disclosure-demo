# 公式与算法源码

正文含五条可编辑 Word OMML 公式，不是图片。Word 公式框切换为 LaTeX 输入后，逐条粘贴下列内容并转换为专业格式。整段伪代码应使用普通段落与框线排版，不要粘进一个公式框。

式（1）：
```latex
H_{t+1}=H_t\cup E(a_t)
```
式（2）：
```latex
D(p)=\left(\bigcup_{a\in p}E(a)\right)\setminus H
```
式（3）：
```latex
p^*=\underset{p\in P(Q,S)}{\operatorname{arg\,min\,lex}}\left(|D(p)|,W(p)\right)
```
式（4）：
```latex
E_1\subseteq E_2\quad\land\quad w_1\leq w_2
```
式（5）：
```latex
\Delta=\Delta_{\mathrm{value}}\cup\Delta_{\mathrm{plan}},\quad\forall k\in\Delta:\ v(k)=v_{\mathrm{current}}(k)
```

D(p) 是新增披露集合；Δ 是核验依赖集合，二者不同。正文下标“值、规划、当前”与这里的英文下标意义一致。H 保守记录已尝试发送的信息，不随修复回退。lex 表示先比较不同披露数，再比较外部执行数。

算法 1 按下列每行排版；上、下使用细横线，输入输出加粗，步骤使用英文。符号可在对应行插入独立 Word 公式，行号和控制词留作文本。

```text
Input: versioned state S, pending steps Q, registry R
Output: checked results C and disclosure history H
1:  C ← ∅; H ← ∅
2:  while Q is not empty do
3:      A, Δ ← EnumerateAlternatives(S, Q, R)
4:      p ← FrontierPlan(A, H)
5:      if p is infeasible then return BLOCKED
6:      a ← First(p); B ← Serialize(a)
7:      T ← Bind(a, Versions(S, Δ), Hash(B))
8:      if not Current(T, S) then
9:          C ← KeepValidPureResults(C, S)
10:         Q ← PendingFromCurrentState(C, S)
11:         continue
12:     if a.recipient = local then y ← Evaluate(a)
13:     else
14:         RequireUnchanged(T, B)
15:         H ← H ∪ DisclosureTokens(a)
16:         y, receipt ← SendOnce(B)
17:         VerifyReceipt(receipt, B)
18:     C ← SavePureResult(C, y, ValueDeps(a))
19:     Q ← RemoveCompletedAndAppendNew(Q, y)
20: return C, H
```

精确选择仅覆盖当前已知的登记等价候选；最坏复杂度为指数级，超过 4,096 个标签明确失败。

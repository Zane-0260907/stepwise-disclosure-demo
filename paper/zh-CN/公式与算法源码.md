# 当前正文的公式与算法源码

正文含六个可编辑的 Word 原生 OMML 公式。每条 LaTeX 单独粘贴到 Word 公式框，选择 LaTeX 输入，再转为专业格式。算法标题、行号、缩进和横线为普通段落；不要把整个算法环境放进一个公式框。

式（1）：有限登记候选中的字典序目标。

```latex
\min_{p\in P,\ T(p)\le B}\operatorname{lex}\left(\left|\left(\bigcup_{a\in p}E(a)\right)\setminus H\right|,W(p),T(p)\right)
```

式（2）：活动集合与退出计数。

```latex
L_i=E_i\cap U_i,\quad z_i=|E_i\setminus U_i|
```

式（3）：共同后缀 F 的成本保持。

```latex
|E_i\cup F|=z_i+|L_i\cup F|
```

式（4）：边界更新，X 为当前活动集合与候选新增项目的并集。

```latex
L'=X\cap U_{i+1},\quad z'=z_i+|X\setminus U_{i+1}|
```

式（5）：活动集合相同的标签之间的支配条件。

```latex
b_1\le b_2\ \land\ (z_1,w_1)\le_{\mathrm{lex}}(z_2,w_2)
```

式（6）：保留标签数上界。

```latex
|\mathrm{Labels}|\le 2^{\omega}(B+1)
```

H 是完整运行历史，不由 z 替代；Uᵢ 只含当前已知后缀仍可能使用且不在 H 中的项目。Eᵢ 为本次规划前缀的新增项目并集。w 为工作量，b 为已消耗的字段次数。式（6）依赖边界宽度和数值预算，不是一般多项式复杂度保证。

## 与正文一致的逐行算法

下面是普通文字行，不需要在 Word 里渲染完整算法环境。正文已排好行号和缩进。

```text
Algorithm 1  Suffix-relevant disclosure planning
Input: known choices A, full history H, field budget B
Output: optimal registered plan, or explicit failure
1:  G ← ComponentsSharingNewTokens(A, H)
2:  for each component g in G do
3:      F[g] ← ∅; U ← KnownSuffixTokens(g, H)
4:      for each attainable field bound b ≤ B do
5:          L ← {(live=∅, retired=0, work=0, fields=0)}
6:          for each step i in original order of g do
7:              N ← ∅
8:              for each label l in L and choice a in A[i] do
9:                  if l.fields + a.fields > b then continue
10:                 X ← l.live ∪ (Tokens(a) ∖ H)
11:                 live′ ← X ∩ U[i+1]
12:                 retired′ ← l.retired + |X ∖ U[i+1]|
13:                 N ← N ∪ Extend(l, a, live′, retired′)
14:             L ← PruneWithinEqualLiveSets(N)
15:             if |L| > LIMIT then return LIMIT_REACHED
16:         if L ≠ ∅ then AddBest(F[g], L)
17:     F[g] ← PruneCostFrontier(F[g])
18: P ← CombineComponentsUnderOneBudget(F, B)
19: if P is empty then return NO_FEASIBLE_PLAN
20: return RestoreOriginalStepOrder(Best(P))
```

第 13 行同时累加工作量、字段次数和路径；第 14 行使用式（5）。第 18 行组合分量前沿，不重排实际执行，实现对组合前沿也应用资源上限。[完整证明](../../docs/live-frontier-proof.md)。

# 公式与算法源码

中文稿中的公式是可编辑 Word OMML，不是图片。Word 公式框可逐条粘贴下列 LaTeX；伪代码的框线、输入输出和行号是普通段落排版，不应把整段 algorithm 环境粘进一个公式框。

```latex
V_t = \pi_{K_t}(S_t)
```

```latex
K_{t+1} = K_t \cup G_t, \qquad G_t \subseteq A(o,r)
```

```latex
D_t = H(S_t[\mathrm{Read}(p_t)])
```

```latex
T_t = (o_t,r_t,v_t,D_t,H(B_t))
```

其中：S 为本地状态，K 为本次可见字段，G 为新申请字段，A 为操作及接收方的授权集合，p 为有限计算表达式，D 为所用源值摘要，v 为授权版本，B 为最终序列化请求。实现对每个依赖字段分别保存摘要，公式中的 H(S[K]) 简写这组绑定信息。

下面是用于 LaTeX 排版系统的等价算法源码（algorithm + algpseudocode）；Word 版本已经按段落排好，不依赖 Word 渲染此环境。

```latex
\begin{algorithm}[t]
\caption{Stepwise Execution and Outbound Validation}
\begin{algorithmic}[1]
\Require State $S$, operation registry $R$, policy $P$
\Ensure Local result and checked execution trace
\While{a registered operation $o$ is pending}
  \If{$\mathrm{LocalRule}(o,S)$ is applicable}
    \State $S \gets \mathrm{Merge}(S,\mathrm{LocalRule}(o,S))$
    \State \textbf{continue}
  \EndIf
  \State $(r,K) \gets \mathrm{InitialView}(o,R,S)$
  \For{each round within the registered limit}
    \State $B \gets \mathrm{Serialize}(o,\pi_K(S))$
    \State $T \gets \mathrm{Bind}(o,r,P.\mathrm{version},S[K],B)$
    \State $\mathrm{RequireCurrentAndUnchanged}(T)$
    \State $(y,\rho) \gets \mathrm{SendOnce}(T,B)$
    \State $\mathrm{RequireMatchingReceipt}(\rho,B)$
    \If{$y$ requests additional fields $G$}
      \State $\mathrm{RequireAllowedNewFields}(G,o,r)$
      \State $K \gets K\cup G$
    \ElsIf{$y$ requests a local program $p$}
      \State $(z,D) \gets \mathrm{InterpretChecked}(p,S)$
      \State $S \gets \mathrm{Merge}(S,z,D)$; \textbf{break}
    \ElsIf{$y$ requests a registered reference}
      \State $S \gets \mathrm{Merge}(S,\mathrm{CheckedLookup}(y))$
      \State $K \gets \mathrm{RebuildView}(o,r,S)$
    \Else
      \State $S \gets \mathrm{Merge}(S,\mathrm{Validate}(y))$; \textbf{break}
    \EndIf
  \EndFor
  \State Fail explicitly if the operation remains incomplete
\EndWhile
\State \Return $\mathrm{AssembleLocally}(S),\mathrm{Trace}$
\end{algorithmic}
\end{algorithm}
```

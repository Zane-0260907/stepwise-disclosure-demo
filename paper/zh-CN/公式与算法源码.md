# 公式与算法源码

正文包含六个可编辑 Word OMML 公式。每条 LaTeX 单独放入 Word 的公式框并选择 LaTeX 输入，转换为专业格式。算法行号、控制词与框线为普通段落排版，整段不要放入公式框。

式（1）：
```latex
H_{t+1}=H_t\cup E(a_t)
```

式（2）：
```latex
D(p)=\left(\bigcup_{a\in p} E(a)\right)\setminus H
```

式（3）：
```latex
p^{\ast}=\underset{p\in P(Q,S)}{\operatorname{arg\,min\,lex}}\left(|D(p)|,W(p),T(p)\right)
```

式（4）：
```latex
B=\left\lfloor(1+\rho)T(p_g)\right\rfloor
```

式（5）：
```latex
E_1\subseteq E_2\ \land\ w_1\leq w_2\ \land\ b_1\leq b_2
```

式（6）：
```latex
\Delta=\Delta_{\mathrm{value}}\cup\Delta_{\mathrm{plan}},\quad\forall k\in\Delta:\ v(k)=v_{\mathrm{current}}(k)
```

P(Q,S) 已包含当前剩余数值字段预算；W 为本地与接收端求值次数，T 为数值字段发送次数。B 是一个状态稳定阶段的共用额度，不是字节上限或跨未来变化的全局界限。H 记录已确认发送的披露项，失败回执不证明没有外发；未知网络状态停止自动执行。

算法 1：
```text
Input: versioned state S, graph Q, registry R, slack ρ
Output: checked results C and disclosure history H
1:  C ← ∅; H ← ∅; B ← UNSET
2:  while Q is not empty do
3:      if StateChanged(S) then
4:          C ← KeepValidPureResults(C, S)
5:          Q ← Pending(Q, C); B ← UNSET
6:      A ← EquivalentAlternatives(S, Q, R)
7:      if B = UNSET then
8:          B ← floor((1 + ρ) × Fields(Greedy(A,H)))
9:      p ← BudgetFrontier(A, H, B)
10:     if p is infeasible then return BLOCKED
11:     a ← First(p); CheckCurrent(S, a)
12:     if a.recipient = local then y ← Evaluate(a)
13:     else
14:         bytes ← Serialize(a); CheckCurrent(S, a)
15:         y, receipt ← SendOnce(bytes)
16:         VerifyReceipt(receipt, bytes)
17:         H ← H ∪ DisclosureTokens(a)
18:     B ← B − NumericFields(a)
19:     C ← SavePureResult(C, y, SourceDeps(a))
20:     Q ← RemoveCompleted(Q, a)
21: return C, H
```

等价候选与表示无关的后续可行性是剪枝保证的前提。最坏复杂度仍为指数级，超过 4,096 个标签明确失败。

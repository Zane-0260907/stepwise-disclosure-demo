# Repository social preview

`social-preview.png` is a 1280 × 640 preview assembled from **this repository's actual saved-run UI screenshot and frozen experiment chart**. Its HTML and rendering script are kept alongside it for provenance. The underlying experiment figure remains available in `evidence/research/results/`.

GitHub currently displays its automatically generated link card. GitHub's documented upload path is: repository **Settings → Social preview → Edit → Upload an image…**. Upload `assets/social-preview.png` there to activate the custom card. The repository file alone does not change the social preview metadata.

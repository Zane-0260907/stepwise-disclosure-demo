# 演示说明

演示要回答两个问题：任务能否完成，以及每一步的接收方实际得到了什么。界面左侧选择运行，中间显示步骤，右侧查看当前步骤的输入、保留字段、请求与接收记录。

## 无密钥体验

1. 运行 `npm ci`、`npm start`，打开本地页面。
2. 点击“真实模型记录”中的“补充必要事实”重放。首次模型请求没有迟延天数；模型提出字段请求，本地核验后才将获准字段加入下一次模型请求。
3. 依次选择首次分析、本地事实补充、再次分析。检查实际请求体和接收摘要，并对照最终计算结果。
4. 本条记录也请求了合同金额；这笔日额计算实际不需要金额，因此属于一次多余业务字段传输。它被保留在原始记录中，不能把“获准发送”解释为“语义上必需”。
5. 选择“引用条款”现场运行本机规则执行器，观察模型形态的分析请求与资料服务请求使用不同字段。页面明确标注本机规则执行器，不把它当成真实模型效果。
6. 选择“发送前人工撤权”，在一次明确的干预点撤销授权，核对该请求没有接收记录。普通运行自动推进，不需要逐步点击继续。

## 使用个人密钥重新执行

在自己的环境变量中设置 `DEEPSEEK_API_KEY` 后启动服务，选择“补充必要事实 · DeepSeek”。该运行会重新读取合成 PDF、调用模型并保存新的轨迹。模型可能请求不同的字段或给出不同结果，不能用它覆盖冻结记录。密钥不写入公开文件。

## 对照与实验

论文当前主图由 `evidence/validation-v4/` 中的 256 次合成强对照和 240 次公开表格任务生成，共 592 次实际供应商调用；单条演示记录不计入批次。强对照共享本地能力，并比较按需补充、关闭补充、获准业务字段全量和业务数值预取。失败保留在分母；没有字段外发的失败任务不能被当成“成功且零披露”。此前 v3 的 448 次任务独立归档。

用户可从请求、字段和源数据一路核对到任务结果。观众无需理解提示词或内部日志格式，也能先在右侧读懂字段变化；需要复核时，再展开实际请求与核验记录。

## 比较本地计算与发送数值

1. 点击“公开表格 · 本地计算”。这是一个预先选定的开发例的真实调用记录，不属于 240 次批量任务。
2. 选择云端规划步骤，展开“问题与表结构”和实际请求。`facts` 为空，但问题、行列标签仍然可见，不能将其称为零信息泄露。
3. 选择“在本地执行计算”，检查模型提出的算式和实际使用的单元格依赖。结果由本地数值计算，未回传给模型。
4. 对同一问题重放“公开表格 · 全部数值”和“公开表格 · 按需取值”，比较外发字段及模型调用次数。
5. 回到批量结果：只发结构的路径通过 51/80 次，全量数值路径通过 62/80 次。单个成功案例不能证明准确率相同；完整记录保留了所有失败。

# v8 证据审查与剩余差距

本轮完成了真实模型计划、按步执行、状态变化、结果复用与实际接收记录的闭环，并加入阶段传输预算。论文、代码和界面使用相同的执行定义。新的受限规划器在 240 个小问题上与穷举最优解相符；这证明给定条件下实现正确，不证明提出了新的通用优化原理。

## 新数据支持什么

24 道公开财务题产生 48 份计划、96 次实际模型调用，每份计划配对六方法和五种条件。保留有效结果使外部调用从 331 降至 261，数值字段从 724 降至 500；各方法的程序执行一致性相同。模型标签一致性与执行一致性分别报告，全部失败、疑似原标签问题及无额外收益结果都公开。

## 为什么不能据此判定研究质量达到 9 分

| 审稿问题 | 当前证据 | 尚未解决的差距 |
|:--|:--|:--|
| 新规划是否优于已有的强策略 | 后续规划与逐步贪心的 240 对执行均有相同披露和字段数 | 未证明新增规划机制在真实模型任务上的收益 |
| 传输预算是否必要且有效 | 有阶段界限、穷举对照和实际执行检查 | 三档预算本批次结果相同，缺乏有代表性的约束生效案例 |
| 是否完成真实模型闭环 | 真实模型申请表结构并提出图，随后执行和处理受控变化 | 图内修复没有触发新一轮模型重规划；不等于任意智能体长期运行 |
| 问题正确性如何 | 与原始标签一致 28/48；两题标签程序疑似冲突 | 尚无独立人审裁定，不能用执行完成率代替答案质量 |
| 任务是否有代表性 | 24 份此前未用年报，来源与筛选公开 | 限于表格算术、一个模型和作者配置的能力边界 |
| 外部基线是否完整 | 旧批次真实调用 FreshCtx 检查组件 | 尚无完整外部智能体系统的匹配端到端比较 |
| 是否满足正式投稿交付 | 四页中文编辑稿、Word 原生公式、完整可复算代码 | 正式英文模板与作者 ORCID、真人评阅仍待后续完成；视频暂缓 |

据这些证据，**尚不足以把技术新颖性或实验说服力判为 9/10**。继续调整标题、增加参数组合或美化 README 都不能填补第一项差距。自评分不是录用概率，也不能取代独立审稿。

## 下一项有意义的研究检验

需要从目标产品的真实任务结构中，先确认跨步骤重用输入、多个可替代接收方和能力变化是否自然出现，再据此冻结任务与强基线。若在同等任务质量、同等能力和同等信息条件下，预算内的后续规划仍无法优于贪心，应收缩算法主张，把稿件定位为可检查执行与披露取舍的系统演示，或调整方法。不能为让新算法获胜而倒推测试模板。

标注疑点需要两位作者独立核查原题和原表，预先确定处理规则，保留原标签与裁定后的两套结果。材料已准备，评阅尚未发生。当前批次不得删除不利样本或追补为“已验证正确”。
